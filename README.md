# 🎧 Spotify Recommendation System

A personal, content-based music recommender built entirely from my own exported Spotify listening history — streaming history, saved library, and playlists. It engineers listening-behavior features (play count, minutes played, recency, playlist membership, artist affinity), computes cosine similarity between tracks, and serves recommendations through an interactive Streamlit dashboard.

---

## ✨ Features

- **Content-based recommendations** — pick one or more seed songs and get back tracks that are most similar based on listening patterns, not just genre metadata.
- **Popularity baseline** — a simple "most preferred tracks" ranking to compare the smarter recommender against.
- **Engineered features** — recency score, plays-per-week, artist-level play/minutes totals, and a weighted preference score combining play count, minutes played, playlist count, recency, and library status.
- **Interactive dashboard** — built in Streamlit with a dark navy background and a pastel pink/mint/lilac "cute-techy" aesthetic, including:
  - Sidebar filters (artist, playlist, recency, library status)
  - A searchable multi-seed song picker
  - KPI cards, a similarity bar chart, and a seeds × recommendations similarity heatmap
  - Plain-language explanations for why each track was recommended

## 🧠 How It Works

1. **`01_Data_Cleaning.ipynb`** — Loads the three raw Spotify export files, standardizes column names, builds a common `track_key` (`"artist - track"`) across all three sources, and merges everything into a single `Tracks_summary.csv`.
2. **`02_EDA.ipynb`** — Explores listening habits: top tracks/artists, listening time by hour/weekday/date, skip rate, playlist composition, and saved-vs-unsaved listening behavior.
3. **`03_Recommendation_Engine.ipynb`** — Engineers recency, consistency, and artist-affinity features, scales them, computes a `preference_score`, builds a cosine similarity matrix over the scaled feature matrix, and saves the trained artifacts (`models/*.pkl`) for reuse.
4. **`src/Recommender.py`** — Wraps the same logic in a reusable `ContentBasedRecommender` class with `popularity_recommendations()`, `content_recommendations()` (supports one or multiple seed songs), and a unified `recommend()` interface.
5. **`Dashboard/app.py`** — Loads `Tracks_summary.csv`, rebuilds the feature matrix and similarity scores, imports `ContentBasedRecommender` from `src/`, and presents everything through the Streamlit UI.

## 🚀 Getting Started

### 1. Clone the repo and install dependencies
```bash
git clone https://github.com/<your-username>/Spotify-Recommendation-System.git
cd Spotify-Recommendation-System
pip install -r requirements.txt
```

### 2. Add your own Spotify data
Request your data export from [Spotify's privacy settings](https://www.spotify.com/account/privacy/) and place the raw JSON files into `Data/Raw/`.

### 3. Run the notebooks in order
```
notebooks/01_Data_Cleaning.ipynb
notebooks/02_EDA.ipynb
notebooks/03_Recommendation_Engine.ipynb
```
This produces the cleaned CSVs in `Data/Cleaned/` and the trained artifacts in `models/`.

### 4. Launch the dashboard
```bash
streamlit run Dashboard/app.py
```

## 📌 Notes

- The dataset has no genre field, so the dashboard uses **playlist membership** as a proxy for genre/mood filtering.
- All personal listening data in `Data/Raw/` and `Data/Cleaned/` is expected to be gitignored — this project is built to run on *your own* exported data, not a shared dataset.
